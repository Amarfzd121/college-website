LOCALHOST PAR WEBSITE CHALANE KA TARIKA

1. XAMPP install karein.
2. ZIP extract karein.
3. Extract hua "college_website" folder C:\xampp\htdocs\college_website naam se rakhein.
4. XAMPP Control Panel mein Apache aur MySQL Start karein.
5. http://localhost/phpmyadmin kholein.
6. Import par click karke is folder ki database.sql file import karein.
7. Website: http://localhost/college_website/
8. Admin: http://localhost/college_website/admin/login.php
